# vFDR — SATA Virtual

**vFDR (Virtual Flight Data Recorder)** é a aplicação de voo da SATA Virtual:
acompanha o teu voo no **MSFS 2024** ou **X-Plane**, envia posições e PIREPs à
companhia e mostra tudo num painel web em tempo real.

> Este repositório contém **apenas as distribuições** (binários e notas de versão).
> O código-fonte é privado.

## Downloads

As versões estão em [**Releases**](../../releases).

Cada versão traz:
- `vfdr-<versão>-windows.zip` — descompactar e correr `Iniciar vFDR.bat`;
- as notas da versão (o que mudou);
- o manual dentro do zip (`MANUAL.md` em português, `MANUAL.en.md` em inglês).

## Requisitos

- Windows 10 ou 11
- Java 21 ou superior — gratuito em [adoptium.net](https://adoptium.net)
- MSFS 2024 ou X-Plane (também funciona em modo offline)

## Atualizações

O próprio vFDR avisa no painel quando existe uma versão nova. Também podes sempre
verificar esta página.

## Instalação

Descompactar onde quiser — não instala no registo nem no Arrancar. As
configurações ficam em `%LOCALAPPDATA%\vFDR\`.
